# Daily Compass

> 🚧 This project is actively being developed.

Daily Compass is a minimal, personal life tracker designed to help users log daily check-ins, track habits, reflect on spending, analyze mood trends, and manage personal goals.

---

## ✨ Key Features

- **Daily Check-ins:** Track mood score, main emotional state, physical/mental tags, active habits, and daily expenses.
- **Goal Management:** Organize personal goals with single-action creation, status tracking, and preset categories (Personal, Health, Learning, Career, Finance, Hobbies).
- **History & Analytics:** Detailed calendar view, monthly/yearly navigation, streak tracking, and interactive AreaChart data visualization with custom glassmorphism tooltips.
- **Check-in Management:** View, modal detail inspection, and deletion of past check-ins.
- **Polished UI/UX:** Built with responsive layouts, empty states, and dynamic toast feedback.

---

## 🛠 Tech Stack

### Frontend
- **Framework:** React + TypeScript
- **Build Tool:** Vite
- **Styling:** Tailwind CSS
- **Routing:** React Router
- **Data Visualization:** Recharts
- **Icons:** Lucide React

### Planned Backend
- ASP.NET Core Web API
- Entity Framework Core
- SQL Server
- JWT Authentication
